# Copy Title and URL 0.1.1

### Changed

- The extension ID now matches the Chrome Web Store item. Unpacked builds and the store version share the same extension ID and Chrome sync rules.
- If you installed 0.1.0 from a release, export your rules before upgrading. The extension ID has changed, so rules saved under the old ID do not carry over automatically.

To migrate, export your rules from the 0.1.0 settings page, remove the old unpacked extension, load 0.1.1, and import the file.

### Fixed

- The Chrome Web Store ZIP no longer contains the `manifest.key` field, which the store rejects.
